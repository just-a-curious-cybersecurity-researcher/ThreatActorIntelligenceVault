# Megazord — Akira-Portal Note

**Variant:** Rust Windows Megazord. **Filename:** `powerranges.txt`. **Extension:** `.powerranges` (uppercase rendering also reported). **Period:** from August 2023; Unit 42 analysis published December 2, 2024.

Unit 42 describes note content resembling Akira and pointing to the same negotiation site. SentinelOne documents an Akira-branded victim portal. These jointly support the relationship for these samples, without establishing exclusivity for every Megazord build. **High Confidence** in filename/family reporting; no complete original plaintext is reproduced here. The available evidence is vendor description and screenshots. [A21](../References.md#a21), [A22](../References.md#a22)

The shift from `akira_readme.txt` and `.akira` accompanies a Rust Windows payload, not the separate Linux Akira_v2 branch. The `--id` execution gate is a binary property; it should not be assumed to be the same field as every victim's portal password. Negotiation and payment instructions remain victim-specific; no universal amount or wallet is supplied by these sources.

The [messaging alternative](megazord-messaging.md) is separately catalogued because its contact mechanism differs. Return to [index](Ransom-Notes.md).
