# Canonical Akira

## Variant, Filename and Period

Early C++ Windows/Linux Akira; `.akira`. Avast documented this filename/template in June 2023; the archive itself does not supply an incident timestamp.

## Known Text and Differences

The opening greeting is **“Hi friends,”**. The text claims backup destruction and theft before encryption, invites a financial negotiation and test decryption, offers a security report, and threatens sale/publication. It directs victims to install Tor and use a provided login code. Those are attacker instructions and promises, not evidence that every claimed action succeeded.
