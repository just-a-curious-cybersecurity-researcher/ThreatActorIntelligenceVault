# Lynx — Ransomware Extensions

**Presentation reviewed:** 2026-10-07.

| Extension | Variant / period | Evidence / confidence |
|---|---|---|
| `.LYNX` / case-insensitive `.lynx` | Windows and documented cross-platform family behavior, 2024 onward | High Confidence; exact casing can vary by display/filesystem |

The `--silent` Windows option can suppress extension and note creation. Absence of `.LYNX` therefore does not exclude execution when other file-format and process evidence exists.
