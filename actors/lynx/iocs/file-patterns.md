# Lynx — File and Note Patterns

**Presentation reviewed:** 2026-10-07.

| Pattern | Context / period | Source / confidence |
|---|---|---|
| `README.txt` | Canonical ransom note written in affected directories | High |
| `README_2.txt` | Tracker archive label for the newer note template; not proven on-host filename | High in archive, Low as emitted filename |
| `%TEMP%\background-image.jpg` | Wallpaper image produced unless disabled | High capability |
| `*.LYNX` | Encrypted output | High; silent mode can omit suffix |
| `w.exe` | Locker filename in the 2025 DFIR case | High in that incident; generic filename |
| `pushprinterconnections.exe` | Masqueraded locker filename in 2026 IR | High in that incident; legitimate Windows name can create false positives |
| `1.exe` | Locker filename in a 2025 analysis | Moderate-High in that incident; generic filename |
| `delete.me` | NetScan share write-access probe | High in case; tool behavior, not locker artifact |
| `netscan.xml`, `netscan.lic`, `ss.xml` | NetScan configuration/licence artifacts | High in case |
| `.nxc\workspaces\smb.db`, `.nxc\nxc.conf`, `nxc.txt` | NetExec workspace/output | High in case |
| `kill`, `delete` | ESXi scripts generated by the Linux build | High capability; generic filenames |
| `rcl.bat`, `nocmd.vbs` | Rclone launch and hidden-console wrapper in 2026 IR | High in reported incidents |
| `SessionGopher.ps1`, `PSTools.zip`, `domain_ips.txt`, `hosts.txt` | Credential, execution and discovery artifacts under `C:\temp` | High in reported incidents; names are not actor-exclusive |
| `connection_trace.txt`, `file_transfer_trace.txt`, `FTCLog.txt` | AnyDesk/Splashtop forensic transfer logs | High evidentiary value; legitimate application artifacts |
