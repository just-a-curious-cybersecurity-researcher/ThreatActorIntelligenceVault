## Analytical Decisions

### Malware family, affiliate and service

The leaked Black builder permits independent payload generation. “LockBit-family binary” and “LockBit service intrusion” are different conclusions. Unit 42's five 2024 possible impostors remain a separate set, and their builder origin is not assumed.

### Naming and cryptographic scope

Original LockBit already included elevation-related behavior in 2020. Black commonly uses generated suffixes and README filenames. Some native 4.0 samples also use hexadecimal extensions, so a 16-hex filename is not exclusive to 5.0.

The supplied statement that Green cannot be used as a 4.0 label is softened: sources reuse that name for different periods/sample sets. NG-Dev is kept separate from later native binaries. Conflicting crypto descriptions are not explained away through an invented builder switch.

Chuong Dong's Red sample analysis identifies AES-128-CBC file processing and a libsodium XSalsa20-Poly1305-BLAKE2b-Curve25519 construction for key protection. The executable analysis retains this sample-specific finding instead of generalizing an AES/RSA description across Red, Black and native 4.0.

The expanded analyses distinguish the symmetric file cipher, asymmetric protection of recovery material, and unrelated encryption of loaders or embedded notes. McAfee/Northwave's AES-protected launcher and LevelBlue's RC4-protected note are not assigned as file ciphers. Calif's modified Salsa20 state, repeated-key defect and file layout describe its Black specimen; subsequent fixes prevent treating that weakness as universal.

Hack & Cheese's historical Linux/ESXi study describes AES and libsodium but equates 32 bytes with 128 bits. The numerical inconsistency is not carried forward as a verified AES key size. Sangfor reports AES-256 and XChaCha20 for Green; that wording remains explicitly attributed rather than merged with other branches. Shared Conti code or a mutex does not establish ongoing operator cooperation.

Sangfor also describes Process32FirstW/Process32NextW as file enumeration. Microsoft's API documentation identifies them as process-snapshot traversal, which is the interpretation used here. Its description of StealBit does not override the transfer-client role established in other primary reporting.

RansomLook's 5.0 report identifies primitives through constants and structure and marks the complete cryptographic wiring as inferred. Its binary-only methodology wording and later detonation descriptions are not reconciled by assuming an independently validated execution trace. The dossier retains the explicitly qualified primitive findings, not a proven universal key schedule.

The detailed Black review adds the public-key-derived mutex documented by Thinkbox alongside the machine-GUID description in supplied advisory material. Trellix's unused legacy AES field is not treated as an active cipher. Northwave's per-action host exclusions are not expanded into an unconditional host-wide exemption. The conventional and reflective DLL interfaces are kept separate.

Calif's Restart Manager registration API is normalized to Microsoft's documented `RmRegisterResources` spelling. The resource-registration call does not itself terminate a process. The associated corruption finding concerns interrupted writes or missing recovery metadata, not a blanket claim that all double-encrypted files are irrecoverable.

Cybereason's detailed build flow establishes public material in the encryptor and private material in the decryptor, despite reversed labels in one command-option table. Its inferred GDEL role and unanalyzed PMOD role are not filled in as confirmed functionality. Kaspersky's deployment percentages describe configuration in its 396-sample corpus, not execution or success rates.

The 2026-09-22 follow-up adds Lexfo's original-generation key hierarchy and Acronis's unpacking/CBC findings. A Run value is described as logon execution rather than an unconditional boot or SYSTEM mechanism. Acronis's F16C/AES-NI equivalence is excluded. Red's worker states distinguish file transformation, finalization and note work.

EQST's early Green cipher description differs from Sangfor's; neither is silently selected as the family-wide specification. EQST's native 4.0 key-material placement also differs from Dong's footer. These remain report/sample boundaries. UPX-like section names are not treated as proof of an ordinary UPX wrapper across all examined 4.0 samples.

S2W's 5.0 key derivation is kept separate from RansomLook's inferred construction. Its cipher/nonce wording does not support a byte-complete validated specification. Service configuration, service stop and process termination remain distinct API effects. Metadata written before content processing is not a completion marker. The reviewed Unit 42 possible-impostor indicator set still supports identification, not a detailed cryptographic reconstruction.

### Incident dates and operator scope

The DFIR Report's 2025 Cobalt Strike/SOCKS article describes a January 2024 intrusion; its 2026 ActiveMQ article describes February 2024 activity. The latter assesses independent leaked-builder use. Publication dates do not create new 2025/2026 incidents, and a Black payload does not establish service membership. The government-agency case contains evidence of multiple intruder groups; earlier artifacts are not all attributed to the final ransomware operator.

### Financial corrections

The 2024 DOJ/Treasury USD 500 million figure explicitly concerns alleged ransom payments; broader damage is separate. The 2023 U.S. USD 91 million measure, the earlier USD 120 million reference and later global allegations have different scopes.

Bitzlato's cited regulatory action is a FinCEN Section 9714 measure, not automatically an OFAC designation. The May 2025 panel leak is a separate event from Cronos.

### Indicator quality

The financial expansion of 2026-09-22 separates designated people, a hosting provider and a possible-impostor artifact. Ten affiliate identifiers and four provider/person identifiers were taken from OFAC notices. The lower-case OFAC SegWit spelling supersedes Chainalysis's mixed-case transcription. No provider wallet is relabelled as LockBit-owned.

The supplied TRM report and the academic study use different address populations and cutoffs. Their active counts are not combined. The paper's pattern counts are internally inconsistent, so no reconciled percentage distribution is repeated. Forbes is secondary coverage of the disclosure; Digital Watch returned 403. The full leaked database, credentials and victim transcripts were not acquired.

The supplied Black hash with 63 hexadecimal characters is excluded and replaced by BRANDEFENSE's verified value. The original-era list is anchored to NHS's 2020 advisory. Acronis labels the supplied `1da6525a...` hash as SmokeLoader; it is not a 5.0 encryptor.

Historical decryptors, builder resources, legitimate utilities and three uncorroborated source leads are segregated. Neither publication dates nor the collection date are invented first_seen/last_seen values. Malformed onion text is not repaired by inference.

### Detection correctness

The supplied Splunk note-or-suffix query applied a suffix regex after its OR selection and therefore discarded note-only hits. L29 preserves the alternatives in one predicate. L28 adds per-process burst context with documented collection requirements.

Internal ETW, SCM and WMI APIs are not represented as command lines that must exist. Public CISA rules retain their artifact scope; locally authored rules and adaptations are labelled explicitly.
