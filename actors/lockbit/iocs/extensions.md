# LockBit — File Extensions

**Presentation reviewed:** 2026-09-17.

| Extension | Variant / period | Evidence / confidence |
|---|---|---|
| `.abcd` | Original ABCD / 2019 | Historical precursor convention |
| `.lockbit` | Original LockBit and Red-era artifacts | Strong historical association; not exclusive and not all later builds |
| Nine-character alphanumeric suffix | Black / 3.0 | Generated build identifier; correlate corresponding README note |
| `.locked_for_LockBit` | NG-Dev / 2024 | Example embedded configuration, not fixed across all builds |
| Randomized hexadecimal suffix | Some native 4.0 samples / 2025 | Independent sample analysis; do not restrict 4.0 to `.lockbit` |
| 16 hexadecimal characters | 5.0 / 2025–2026 | Trend Micro observed behavior; useful heuristic, not exclusive version proof |

Quiet/invisible settings can suppress renaming. The absence of these suffixes does not exclude encryption.
