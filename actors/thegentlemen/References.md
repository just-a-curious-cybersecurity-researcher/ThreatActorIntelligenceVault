## Executable Analysis Provenance

The Windows narrative restructures the supplied execution research and is checked against G01/G02, with cross-checks against G13. Command names, service/task identifiers and file markers are technical recognition artifacts; illustrative mockups are original, non-executable examples. G01 adds precise task/Run names; G13 supplies the separate ESXi behavior. Mockups are original explanatory pseudocommands, not recovered source or new indicators. This is recorded explicitly; a build difference is not asserted without sample-level verification.
