## Known Text and Differences

The note says files were encrypted and data was stolen, describes the motive as financial, warns against third-party recovery and directs the victim to a private chat using a supplied ID. The archived version gives ten days to establish contact, followed by a three-day publication countdown. Those deadlines are note text, not proof that every negotiation followed them.

## Contact and Infrastructure

The document provides two Tor chat endpoints and advertises the SafePay publication site through Tor and a TON mirror. It does not publish a reusable Bitcoin address; payment details are expected to be negotiated per victim.

The full note is available through the [ransomware.live archive](https://www.ransomware.live/ransomnote/safepay/readme_safepay.txt). Archive rendering was cross-checked against RansomLook. Local analysis avoids copying the full demand text.
